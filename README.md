# PM 工具手冊（通用版）— 索引

適用任何產業的 PM / PO。範例皆為 SaaS / 電商等虛構的中性情境。

**關於文中的 Skill / Command：** 01、02、03 整理自 Claude Code 的 PM 外掛（01、02 來自開源的 [phuryn/pm-skills](https://github.com/phuryn/pm-skills)）。文中的 `/discover`、`/strategy` 等指令要安裝對應外掛才能執行；沒有安裝的話，把每一節當成流程與檢查清單閱讀即可。

| 檔案 | 來源 | 內容 |
|---|---|---|
| [01-product-discovery.md](01-product-discovery.md) | pm-product-discovery | 13 個 skill + 5 個 command：發想、假設辨識與排序、實驗設計、功能優先序、需求分流、Opportunity Solution Tree、訪談腳本與摘要、指標儀表板 |
| [02-product-strategy.md](02-product-strategy.md) | pm-product-strategy | 12 個 skill + 5 個 command：產品願景、Strategy Canvas、Startup / Lean / Business Model Canvas、價值主張、變現與定價、SWOT、PESTLE、五力、Ansoff |
| [03-po-interview-and-sparring.md](03-po-interview-and-sparring.md) | po-item-interview、po-direction-sparring | 五題 item 訪談與一致性檢查；方向提案陪練的 6 個階段、數字檢查清單、主管題庫，以及 DECISIONS / HANDOFF / REHEARSAL 模板 |
| [04-business-proposal.md](04-business-proposal.md) | 公開框架整理 | 商業提案寫法、模板、商業模式圖與送出前的自我檢查 |

## 建議使用順序

1. **探索問題**：01 的 discover / interview → opportunity-solution-tree
2. **定方向**：02 的 strategy / market-scan；03 的 direction-sparring
3. **寫提案**：04 的模板與逐節教學；用 01 的 identify-assumptions 找出未驗證的假設
4. **拆成工作項目**：逐條 item 用 03 的 item-interview
5. **追蹤成效**：01 的 metrics-dashboard
